Description

OpenWXSDR is a real-time radiosonde reception and decoding system for amateur radio enthusiasts. The system receives radiosonde signals via RTL-SDR hardware and decodes telemetry data in real-time.

Key Features
  • Real-time radiosonde tracking with live map display
  • Support for multiple RTL-SDR devices simultaneously
  • MQTT and HTTP upload to OpenWX.de
  • Automatic frequency scanning and sonde detection
  • RS41, RS92, DFM, M10, M20 and other sonde types

Beschreibung

OpenWXSDR ist ein Echtzeit-Radiosonden-Empfangs- und Dekodiersystem für Amateurfunk-Enthusiasten. Das System empfängt Radiosondensignale über RTL-SDR-Hardware und dekodiert die Telemetriedaten in Echtzeit.

Hauptmerkmale
  • Echtzeit-Radiosonden-Tracking mit Live-Kartenanzeige
  • Unterstützung mehrerer RTL-SDR-Geräte gleichzeitig
  • MQTT- und HTTP-Upload zu OpenWX.de
  • Automatische Frequenzsuche und Sondenerkennung
  • RS41, RS92, DFM, M10, M20 und weitere Sondentypen
